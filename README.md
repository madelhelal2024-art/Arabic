# عَرَبِيَّةُ الْقُرْآنِ — Arabic Light Academy

تطبيق ويب تعليمي تفاعلي لتعلّم العربية من سور القرآن الكريم.

## المحتوى الحالي

- أربعة كتب: الطالب، التدريبات، الإعراب، القواعد.
- فهرس سور القرآن الـ114، مع بداية المحتوى التفاعلي من سورة الناس.
- تلاوة الآيات والسورة بصوت الشيخ محمد صديق المنشاوي عبر Al Quran Cloud.
- تدريب تفاعلي، متابعة التقدم، حفظ الآيات للمراجعة.

التطبيق في مرحلة الإصدار التأسيسي؛ ستضاف بقية السور بعد المراجعة التعليمية.
